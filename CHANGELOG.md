# Changelog

## v1.0.0 — 2026-05-29

Initial release.

- Local, no-key learning-path tracker: phases, resource links, progress, and a "Read Next" suggestion.
- Per-phase **Overview** modal (summary, goal, milestone, concept chips).
- **Inbox** + per-card phase/priority assignment; mark done/undone; delete.
- Fast search; a single editable `plan.json`; ships an empty template + an anonymized AI/ML starter pack.
- **Optional AI** (no agent needed): Auto-sort the Inbox and Re-enrich links via any OpenAI-compatible endpoint (hosted key or local Ollama). Disabled by default.
- Distinctive dark "Observatory" theme with accessibility (focus rings, `prefers-reduced-motion`, dialog focus traps).
