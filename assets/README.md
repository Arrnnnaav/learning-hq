## `demo.gif` (record this — ~20s)
A short loop is the single highest-impact thing for Show HN / Reddit clicks.

**Tool:** [ScreenToGif](https://www.screentogif.com/) (Windows) or macOS Cmd-Shift-5 → convert to GIF (e.g. Gifski). Keep it under ~6 MB and ~1000px wide.

**Shot list (record at http://localhost:3000):**
1. Paste a URL in the add bar → press Add → it appears in **Inbox** (1–2s).
2. On the card, change the **phase** dropdown → the link moves; toggle **Done**.
3. Click a phase in the sidebar → click **ⓘ Overview** → modal shows summary + concept chips → Esc.
4. (If AI configured) click **✨ Auto-sort** on the Inbox → links fan out into phases.

Drop the file here as `assets/demo.gif`. The README shows it automatically once present.
